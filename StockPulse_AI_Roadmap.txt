StockPulse AI - Project Roadmap

Project Goal

Build a real-time market intelligence platform that ingests financial
news, social media, and market data, stores and processes it using a
custom Redis database, predicts short-term stock movement using machine
learning, and displays everything in a live dashboard.

Backend API

Routes - GET /market - GET /stock/{ticker} - GET /predict/{ticker} - GET
/news - GET /health - POST /train

------------------------------------------------------------------------

Redis Design

Streams - news_stream - reddit_stream - market_stream -
prediction_stream

Hashes - stock:{ticker} - price - volume - sentiment - prediction -
confidence

Lists - recent_news:{ticker}

Sorted Sets - trending_stocks

------------------------------------------------------------------------

Data Pipeline

1.  News Worker

-   Fetch latest articles
-   Push to Redis Stream

2.  Sentiment Worker

-   Read Stream
-   Run FinBERT
-   Store sentiment

3.  Market Worker

-   Download market data
-   Compute indicators

4.  Feature Worker

-   Combine market, news, sentiment

5.  Prediction Worker

-   Run ML model
-   Store prediction in Redis
